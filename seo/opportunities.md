## First Sprint

1. Export Ahrefs Organic keywords for US, UK, and Canada.
2. Run `npm run seo:score-ahrefs` for each export.
3. Refresh the highest-priority page where iCloseLeads already ranks between positions 4 and 20.
4. Build one supporting post for the highest-scoring keyword where the ranking page is underpowered.
5. Add internal links from existing blog posts into the matching money page.
6. Create a backlink prospect list from competitor pages that link to practical lead-generation resources.

## Page Improvements To Check Next

- Homepage: make sure first viewport reinforces "freelance lead generation software" and links to remote jobs, local business leads, live jobs, decision makers, and AI proposals.
- Feature pages: each page should have one primary keyword, one pain-led intro, product screenshots or workflow copy, FAQ schema, and internal links.
- Blog pages: keep pagination, featured images, internal links, comments, author/date, and "next action" CTAs.
- Local business leads page: reinforce "web design leads" and "businesses without websites" in public-facing content, not dashboard-only UI.
- Decision maker feature: present it as owner path verification rather than pretending every owner name/phone can be fetched automatically.
