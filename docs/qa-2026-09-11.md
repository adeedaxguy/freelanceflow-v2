# iCloseLeads QA - 11 September 2026

## Verdict

The main search and navigation paths work, but this is **not a clean release sign-off for every feature**. Real searches returned results and preserved context. Several quality, trust, accessibility, and failure-handling gaps remain. Page availability and passing mocked tests do not prove successful customer payments, email delivery, or telephone audio.

Baseline: `d6384f4` on `main`, production `https://icloseleads.com`. The unrelated blog changes already in the working tree were preserved and excluded from this QA change.

## Fixed In This Change

- Help search was an inert field. It now performs an accessible native GET search over questions and answers, with an empty state and clear recovery. Structured data matches the visible answers.
- Help category counts now reflect actual answers. Missing Account/API anchors are present and the API documentation link points to `/developers`.
- Stale help billing/downgrade copy now matches the three-day trial. Unsupported client-success and support-response-time claims in the edited answers were removed.
- API documentation no longer causes whole-page horizontal overflow at 390px. Long code examples scroll within their own area.
- All five lead-calculator sliders have accessible names; its CTA now explicitly offers a free three-day trial.
- Unauthorized `GET` and `PATCH /api/admin/users` now return 403 rather than misclassifying denied access as a server failure. There was no observed user-data disclosure.
- Website concept testimonials are visibly labelled as illustrative, unverified copy, including client-facing previews. The testimonial feature remains present.
- Seven regression tests cover help behavior and admin access/error distinctions. No package, schema, Stripe, Twilio, or production credential changes.

## Release Boundaries And Next Gate

This QA change is intentionally limited to the fixes listed above. No live billing mode was changed; no customers were messaged, charged, called, upgraded, or deleted. Temporary browser tabs, test browsers, and local servers were closed after use.

Before a full production sign-off, address the P1 findings, then use dedicated non-admin test identities to verify active and expired trial access, paid entitlement activation/cancellation, support and password-reset delivery, saved-work mutations, and one consented end-to-end telephone call. Include mobile authenticated workflows, browser/device variation, provider timeouts, concurrent requests, and recovery without data loss. Do not describe the platform as flawless or unhackable.

Raw local evidence and screenshots are in the ignored `reports/qa-complete-public.json`, `reports/qa-fix-local.json`, `reports/qa-dependency-audit.json`, and `reports/qa-*.png`. They are not committed as customer-data artifacts.
